# components/

## minionBattlesHomePage/

Full-page panel components rendered as tabs inside `CampaignHomeScreen`: `BestiaryPanel`, `AdminPlayersHomePanel`, `PlayerCharactersPanel`, `LobbyArchive/LobbyArchiveTab`, and `TerrainEditor/TerrainEditorTab`. All use `PanelLayout` — the shared viewport-height-bounded card with optional left/center/right columns — which also lives here.
