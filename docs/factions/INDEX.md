## How to use this index

1. Match keywords from your task to a faction row.
2. Open the linked doc — read the thematic primer first, then mechanical primer, then the code map.
3. Do **not** duplicate roster tables here; this file is navigation only.
4. For cross-cutting mechanics (light grid, team IDs, unit stats), start with the code map in the relevant faction doc.
